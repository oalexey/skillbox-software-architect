## 6. План поэтапной разработки и расширения системы

План показывает очередность реализации бизнес-требований и связь с концептуальной архитектурой.

### Фаза 0. Основание и приватность

**Цель:** создать безопасный фундамент, без которого нельзя строить глобальный продукт.

| Что делаем | Требования | Архитектурные компоненты |
|---|---|---|
| Единый вход, профиль, возрастные категории, согласия | FR-01, FR-17 | Identity/SSO, Consent/Privacy, Profile |
| Базовая платформа: CI/CD, IaC, observability, security baseline | Все | Платформенные сервисы |
| Классификация данных, retention, права субъектов | Все | Data governance |
| Модерация и safety baseline | FR-16 | Moderation/Safety |
| Архитектура офлайн-синхронизации | FR-02 | Client SDK, Sync/Activity |

**Критерий выхода:** пройден security/privacy review, готовы шаблоны развертывания, утвержден детский режим.

### Фаза 1. Минимально ценный продукт

**Цель:** доказать, что приложение помогает тренироваться регулярно и связано с продуктами компании.

| Бизнес-требование | Реализуемые возможности | Компоненты |
|---|---|---|
| Тренировка и прогресс | запись тренировки, история, сравнение с собой | Activity, Training BFF, Time-series |
| Планы и расписания | базовые планы, рекомендации, цели | Plans/Coaching |
| Инвентарь | добавление обуви/снарядов, пробег, износ | Equipment |
| Социальный минимум | группы по интересам, вступление, события группы | Social/Community |
| Уведомления о достижениях | пользователь делится успехом, друзья получают уведомление | Notification Hub |
| Геймификация | бейджи, серии, простые челленджи | Gamification |
| Промо и новости | контекстные промо, региональные кампании | Commerce Integration, Promo |
| Покупки | SSO с существующими приложениями, каталог, переход к покупке | Commerce Integration |
| Устройства | телефон, HealthKit/Google Health Connect, BLE-пульсометры | Device Integration |

**Критерий выхода:** пилот в 1–2 регионах, стабильная запись тренировок, первые группы, интеграция с магазином, отсутствие критических инцидентов приватности.

### Фаза 2. Рост сообществ и персонализация

**Цель:** усилить социальные связи и сделать продукт более «живым».

| Бизнес-требование | Реализуемые возможности | Компоненты |
|---|---|---|
| Поиск людей по интересам и местам | поиск с приватными настройками, геофаззинг | Search/Discovery, Privacy |
| Совместные тренировки | события, приглашения, RSVP | Social, Events |
| Расширенная геймификация | лиги, сезонные челленджи, командные цели | Gamification, Competitions |
| Региональные и поведенческие промо | более точные кампании по типу тренировок | Promo, Analytics |
| ML-рекомендации | планы, контент, товары | Recommendation engine |
| Продвинутые устройства | больше датчиков, качество данных | Device Integration |
| Сравнение с регионом и профессионалами | агрегированные бенчмарки | Analytics, Activity |

**Критерий выхода:** рост доли пользователей в группах, подтвержденная ценность поиска людей, стабильная работа соревнований среднего размера.

### Фаза 3. Масштаб и экосистема

**Цель:** поддержать массовые события, глобальный рост и глубокую интеграцию с коммерцией.

| Бизнес-требование | Реализуемые возможности | Компоненты |
|---|---|---|
| Массовые соревнования | крупные события, лидерборды, антифрод | Competitions, Fraud detection |
| Дикие места и офлайн | улучшенный офлайн, предзагрузка карт/маршрутов | Activity, Client SDK |
| Профессиональные сценарии | расширенная аналитика, экспорт, интеграция с тренерами | Activity, Analytics |
| Глубокая коммерция | рекомендации товаров по тренировкам, износ, сезонность | Commerce, Recommendation |
| Партнерские интеграции | внешние события, клубы, тренеры | Integration layer |

**Критерий выхода:** платформа выдерживает пиковые события, стоимость владения контролируема, приватность и безопасность не деградируют.
