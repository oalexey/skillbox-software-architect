## 3. Стейкхолдеры и их интересы

| Стейкхолдер | Интересы | Влияние | Риски/ожидания |
|---|---|---|---|
| Конечные пользователи: профессионалы | Точная телеметрия, сравнение, производительность, интеграция устройств | Высокое | Ошибки данных, потеря тренировки, приватность |
| Любители и новички | Простота, мотивация, планы, прогресс, безопасность | Высокое | Слишком сложный онбординг, навязчивые промо |
| Дети и родители | Безопасность, контроль, отсутствие публичности | Высокое | Юридические и репутационные риски |
| Тренеры и спортивные клубы | Планирование, группы, события, аналитика | Среднее | Нужны удобные инструменты, но без лишней сложности |
| Локальные сообщества | Совместные тренировки, маршруты, события | Среднее | Модерация, злоупотребления, спам |
| Маркетинг и бренд | Вовлечение, промо, лояльность, бренд-предпочтение | Высокое | Риск навязчивости и нарушения приватности |
| E-commerce / продажи | Конверсия, повторные покупки, интеграция каталога | Высокое | Излишняя коммерциализация может ухудшить доверие |
| Юристы, комплаенс, DPO | GDPR, CCPA/CPRA, LGPD, PIPL, COPPA/детские данные, согласия | Очень высокое | Штрафы, блокировки, репутационные потери |
| Информационная безопасность | Защита данных, управление доступом, устойчивость к атакам | Очень высокое | Утечки, компрометация аккаунтов |
| Продуктовые команды | Скорость экспериментов, A/B, feature flags | Высокое | Сложность платформы может замедлить разработку |
| Разработка и архитектура | Масштабируемость, модульность, понятные контракты | Высокое | Технический долг, зоопарк технологий |
| Data Science / аналитика | Качество данных, персонализация, ML | Среднее | Плохое качество данных, смещения, этические риски |
| Спортивная наука | Корректность рекомендаций и метрик | Среднее | Неверные советы, риск для здоровья |
| Партнеры по устройствам | Интеграция, сертификация, стабильность API | Среднее | Фрагментация устройств и протоколов |
| Облачные провайдеры | Надежность, соответствие региональным требованиям | Среднее | Стоимость, vendor lock-in, локальные сбои |
| Регуляторы | Соблюдение законов о данных, детях, потребителях | Высокое | Запреты, проверки, штрафы |
| Поддержка | Диагностика проблем, простые процедуры | Среднее | Сложность распределенной системы |
