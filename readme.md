# Архитектурный проект: глобальная спортивно-социальная платформа

Ниже представлено архитектурное предложение по созданию приложения/платформы, которая:
- помогает людям регулярно тренироваться и прогрессировать;
- формирует социальные группы и сообщества вокруг спорта;
- стимулирует спрос на продукцию компании через персонализированные, этичные и ненавязчивые триггеры;
- учитывает глобальный масштаб, мультиоблачность, офлайн-сценарии, детские аудитории, носимые устройства и повышенные требования к приватности.

### Ключевые допущения

1. Приложение не является медицинским изделием.
Данные о пульсе, кислороде, сне и т.п. рассматриваются как фитнес-данные, но могут относиться к чувствительным категориям. Обработка — только при явном согласии, минимально необходимом объеме и с возможностью удаления.
2. Детская аудитория обрабатывается в специальном защищенном режиме.
Для детей до 13/16 лет в зависимости от региона:
- родительское согласие;
- ограниченные социальные функции;
- отсутствие публичного профиля и точной геолокации;
- запрет персонализированной рекламы без согласия родителя/опекуна;
- усиленная модерация.
3. Мультиоблачность сохраняется, но критичные компоненты проектируются переносимыми.
Компания использует разных облачных провайдеров под разные задачи. Архитектура должна избегать жесткой привязки к одному вендору в критичных местах: идентичность, данные тренировок, события, экспорт, аналитика, согласия.
4. Не все требования одинаково важны на старте.
Часть социальных функций, точный поиск людей рядом, массовые соревнования и продвинутые датчики вводятся поэтапно после проверки ценности и рисков.
5. Основной продуктовый принцип:
«Если у вас есть тело — вы спортсмен» означает инклюзивность: новички, любители, профессионалы, люди с ограниченными возможностями, дети, семьи, возрастные пользователи.
